# 首次公开发布检查

日期：2026-09-21。范围包括 Git 公开文件集、六份设计文档、示例素材、测试截图和记录，以及发布的 SDK/CLI/静态站点与源码压缩包。

## 发现与处理

- 原测试日志和浏览器结果包含开发机绝对路径；公开副本已替换为通用路径，生成脚本也执行相同处理。原始本地记录留在忽略目录。
- 旧的程序包包含编译时的本机路径；SDK 构建加入路径重映射，CLI 开发模式的 SDK 查找改为相对路径，并重新生成程序包。
- 发布打包采用与 Git 一致的公开文件集，不递归收集本地状态。忽略本地配置、凭据文件、缓存、原始测试记录及运行数据。
- 压缩包不写入本机用户名、用户组或文件时间；提交作者使用 GitHub noreply 邮箱。
- 检查了令牌、私钥、带凭据的链接、凭据配置、私人联系方式和内网地址，并复核了引用链接。没有发现需要保密的账号凭据或私人内容。
- 示例图片和声音由项目脚本生成；截图只包含游戏画布。检查图片和声音容器未发现私人元数据。字体及依赖保留公开的上游权利信息。

## 许可

项目原创代码使用 **LGPL-3.0-or-later**。包含完整 LGPL v3、其引用的 GPL v3、项目授权说明和构建方法。原创示例图像及声音保留 CC0-1.0；字体保留 OFL-1.1；第三方代码保留原许可。SDK 的许可汇总覆盖播放器和 CLI。
