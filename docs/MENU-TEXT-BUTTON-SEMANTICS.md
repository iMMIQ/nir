# 菜单文字按钮

`ui.menu-text-button.v1` 增加有限 `TextButton` 元素，用于来源引擎的文字菜单。它复用 MenuElement 的位置、缩放、透明度、裁切、条件、父容器与菜单控制请求，不要求先把文字转为图片。

```json
{
  "id":"resume", "rect":[177,73,400,44],
  "content":{
    "type":"text_button", "label":"Resume", "size":26,
    "color":[1,1,1,1], "hover_color":[0.5,1,1,1],
    "disabled_color":[0.5,0.5,0.5,1],
    "action":{"type":"close"}
  }
}
```

label 是绘制正文与辅助语义的同一份固定字符串，非空且最多 1024 UTF-8 字节。size 为有限的 8–128；普通、悬停和禁用颜色均显式声明，各分量处于 0–1。禁用状态优先于悬停，不额外套用固定透明度。父透明度、裁切和玩家字号偏好继续生效；点击区使用作者 rect，不按字形轮廓缩小。

沿用作者正文语言的字体计划与塑形，不引入系统字体名称或运行时字体查找。所有按钮标签进入作者字体字集和覆盖校验，缺字不能靠辅助标签显示成功来掩盖。该元素计入现有最多 64 个文字批次预算，不提高资源或控件数量限制。

可选 requires 与祖先条件共同决定可用性；禁用控件仍阻止点击穿透。指针悬停与共享键盘焦点使用相同选中控件身份，动作仍提交 instance/revision/control 并在 Player 复查。文字标签、绘制、语义与动作属于同一个元素，不能通过显示颜色改变执行权限。

TextButton 暂不接受 text_local/text_preference/text_slot 动态正文绑定，避免绘制内容与辅助标签不同步。可放入 Stack 中使用显隐条件紧凑排列。行高由 rect 与 Stack 决定，不承诺原引擎字体的字面高度、描边、行距或自动宽度已完全等价。

源 Program、runtime root 均要求能力声明；编译器按实际使用保留。原版文字菜单的属性提取、字体替代政策、条件和回调转换仍需另外校验，本能力本身不代表完整来源菜单已自动生成。
