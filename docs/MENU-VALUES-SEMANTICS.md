# 有界菜单值控件

能力：`ui.menu-values.v1`，同时使用菜单元素和菜单服务能力。页面局部绑定仍需声明菜单状态能力。

- Toggle 绑定局部 Bool 或玩家 reduced_motion；Range 绑定局部有界 Int 或现有数值偏好。
- Range 明确 min/max/step，所有值有限，最多 1000 个间隔。局部 Int 的边界、步长必须是整数，并限于 f32 精确整数范围；偏好边界不能超出对应服务范围。
- 可选原图包括开关的 on/off 图片及滑条的 track/thumb 图片；无图片时使用内置绘制。滑条当前不支持原引擎的两端增减按钮与九宫格切片。
- 指针松开且仍命中同一会话、交互、页面实例、版本和控件时提交一次。拖动中不修改值；取消、离开画布或版本变化丢弃手势。当前不捕获画布外拖动。
- 左/下减一步，右/上增一步，Home/End 取端点。Tab 继续导航。开关使用 Enter/Space。
- 输入在 Player 再次验证绑定、可见性、启用状态、范围及版本。取最近步长，最大端点可达；非有限数、越界值、错误值类型及旧动作不写入。
- 每次接受的输入推进页面版本；键盘焦点保留实例和控件身份，刷新后的动作使用新版本。Web 提供 slider/switch 辅助语义。
- 持久偏好继续走现有服务；局部值保持页面生命周期，不进入 Story 快照。文本标签计入页面文字预算，并进入字体收集。

## 转换边界

控件契约可由转换器生成，但不能据此宣称任何来源控件已完成迁移。来源量纲、范围、回调、状态条件、资源和布局均需分别映射。

当前 LiveNovel 标题与回想按钮已输出有限页面元素；系统设置菜单尚未映射到这些值控件。源码样例的音量比例可线性换算；自动等待的绝对时长和播放器的等待倍率不是同一语义，禁止直接替换。原版视觉/声音实机认证仍待完成。
