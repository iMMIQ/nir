# 对白与语音实例边界

本增量实现 `text.voice-binding.v1`，同时提供玩家字速和自动等待偏好；提供 Ctrl held-skip、临时隐藏和共享推进路由；原生完整焦点导航仍待交付。

## 显式绑定

```json
{
  "id": "bind-page-voice",
  "operation": {
    "type": "dialogue_voice",
    "task": "line",
    "voice": "spoken",
    "wait": "parallel"
  }
}
```

操作执行时，task 必须解析到活动 Dialogue，voice 必须解析到具体的非循环 Voice 总线 Audio 实例。它可以在页首或页内 Gate 后执行，不消费 Gate、不改变文字揭示、不启动声音。`voice: null` 明确表示这段对白不等待语音；未执行过绑定操作的旧作品仍保留原先扫描活动 Voice 总线的 Auto 策略。

绑定保存实例 ID，不随符号句柄后来复用而改变。重复绑定替换关联并增加有界 revision，使 Player 重新计算该段自动等待。已结束的声音可以被绑定，此时不再等待。循环 Voice 和其他总线不允许作为阅读语音。

源与惰性验证检查能力声明和任务类型，分模块运行时还拒绝跨模块引用；同名句柄可以在别处声明循环声音，但实际绑定时仍拒绝循环实例。程序未声明能力、缺少目标或者目标类型错误均失败，不默默回退到总线扫描。

## 三种边界与 Auto

Dialogue.interaction 标识当前 NIR 语义交互，Gate 表示交互内部必须由唯一 VM 解除的边界。阅读视口的布局翻页不产生新的 Dialogue，不改变语音关联，也不触发源页停止。

LiveNovel 导入将一页映射到一个 Dialogue：前缀事件先执行，再在页首绑定当前非循环语音；页内事件在 Gate 处执行后重新绑定，再解除 Gate。源页完成后仍使用原来的 50 ms AudioStop，循环 Voice 不作为本页阅读语音。绑定本身不隐含停止声音，不替代源页结束逻辑。

绑定支持下列有限等待策略：

- `parallel`：文字全部揭示后的阅读等待与语音并行，等待时间到且绑定实例已结束才能自动前进。
- `after_voice`：绑定实例运行期间不累积阅读等待；结束后再等待完整阅读时长。
- `sampled_remaining`（另需 `text.voice-timer.v1`）：Auto 周期开始时采样绑定语音的剩余时长，与阅读等待相加并冻结；之后语音提前结束、取消、静音或取消静音均不改变该周期的截止时间。只有采样时玩家 Voice 音量大于 0、绑定实例仍运行才加入余量。优先使用最近设备位置，否则用 Story 任务 elapsed；余量下限为 0。不等待无关 Voice，循环语音不可绑定，缺少音频时长元数据的作品拒绝验证。

默认 `player.auto_delay_policy = "length_scaled"` 保留作品 auto_delay_us 加文本长度系数，再乘玩家 auto_wait_scale。`fixed`（需 `player.auto-delay-policy.v1`）仅使用 auto_delay_us 乘倍率，不追加字符时间；允许 0–30 秒，旧策略仍要求 0.1–30 秒。固定零等待仍受 VM/输入预算、Gate 和选择约束。
`sampled_remaining` 只对阅读部分应用 auto_wait_scale，语音余量不乘倍率；文本已就绪时，开启 Auto 的输入动作当场采样；否则在文本进入阅读边界时采样，不把该边界之前的 Tick 时间计入新周期。Auto 的计时归属由会话、交互和绑定 revision 决定，不能带入下一页或新会话；不越过硬 Gate 或选择。前两种策略中，绑定实例完成、取消或失败均不再视为正在说话；采样计时保持既定截止时间。具体剧情分支仍由原有 Await 处理。

## 玩家阅读偏好

`text_speed` 与 `auto_wait_scale` 都是 0.25–4 的有限倍率，默认 1。它们是 Player 偏好，不要求作品声明新能力；不增加剧情指令，也不改变 Story 时间、声音或动画速度。旧偏好记录缺省为 1。

`auto_wait_voice` 是默认开启的玩家布尔偏好；旧记录缺字段也为 true。开启时保留作品声明的 parallel / after_voice / sampled_remaining 策略；没有绑定的旧作品扫描活动非循环 Story/Voice。循环 Voice 属于持续声音，不参加额外等待，避免永远不结束的实例卡住自动阅读；自动翻页不会因此停止循环声音。关闭时只取消 Player 自动阅读的额外语音等待，不增加采样余量，也不在语音后重新等待。文字仍须揭示完成，作者显式 Await、Gate 和选择仍然有效；此设置不停止声音或改写作者清理声音的指令。

等待语音选择在自动周期的阅读边界冻结。修改设置、菜单和后台不会改变已经开始的周期；下一句、绑定 revision 变化、手动推进或关闭再开启 Auto 时应用新选择。内置设置提供可滚动的开关，Web 和原生存储均保留它；读档不回滚当前偏好，成功读档默认关闭 Auto/快进并等待玩家继续。声音恢复政策另见 AUDIO-SEMANTICS.md。

`voice_continue` 是默认开启的玩家布尔偏好，旧记录缺字段也为 true。开启时保留作者的声音任务生命周期；关闭时，仅在当前 Dialogue 真正完成的同一 VM 输入事务中停止它关联的仍运行语音。揭示文字、浏览同一句的窗口分页、Gate、菜单、加载屏障和过期输入均不触发停止。设置变更本身不截断声音，从下一次真实推进生效；手动与自动推进使用相同策略，`auto_wait_voice` 仍单独决定自动是否额外等待语音。

显式绑定过的多个语音实例保存在 Dialogue 的 `reading.active_voices` 中，不依赖可被裁剪的历史。实例结束后移出列表；绑定 `voice: null` 清除本次自动等待，但不解除先前仍运行的关联语音。未绑定的 Voice、循环 Voice、BGM、Sfx 和前台历史重播不属于这份关联。旧作品完全没有 reading 绑定时，沿用活动非循环 Story/Voice 的扫描策略；旧快照缺 active_voices 时仍能处理最近绑定。列表受运行任务预算约束，恢复检查唯一实例及仍运行的非循环 Voice 类型。

已读快进和按住快进在真实完成 Dialogue 时总是清理上述语音，与续播开关无关；遇到未读或 Gate 不停止声音。策略停止使用作者 AudioStop 一致的 CancelledByControl 终态，不伪造自然结束或 finished 里程碑。作者显式 Await/Gate 不会因点击被绕过；若作者等待的语音确实被停止，原有 on_cancelled 分支照常生效。默认续播不会延长作者显式停止、作用域退出或会话清理的声音。

内置设置提供 44px 的续播开关，Web/原生偏好存储均保存它。读档保留当前全局选择，不从游戏快照回滚。续播只改变本句推进的停止策略，不更改音量、解码格式或设备恢复政策。

Web 的输出恢复等待独立于菜单、后台和作者等待。恢复点击、画布点击与 Enter/Space 只恢复声音，不推进正文；按键重复不追加恢复请求。输出报错或恢复迟迟未完成时，提示保留阅读位置，并提供“打开存档”。提示区内的原生按钮保留键盘激活，玩家可选择槽位保存当前进度；打开存档不解除其他暂停所有权，也不自动保存或覆盖槽位。具体失败提示及设备状态验收边界见 PLAYBACK-EXPERIENCE.md。

已就绪页面开启 Auto 时当场建立周期。文字或语音后等待在一次较长的 Tick 中进入阅读边界时，只计入该边界之后的时间；不能把整段文字揭示或语音淡出时间计入阅读等待，导致刚显示完就自动翻页。采样余量策略仍从采样当下冻结截止时间。

- 字速越大揭示越快。在准备新 Dialogue 时将作者 reveal_us 除以 text_speed，四舍五入为微秒并冻结；运行时最小间隔为 1 微秒。Gate 和窗口翻页不重新采样偏好，后续新 Dialogue 使用最新设置。
- 自动等待越大停留越久。在下一次实际开始累积 Auto 等待时冻结时长；并行策略在文字就绪后采样，语音后等待策略在语音结束后采样。修改设置、打开/关闭菜单不重算正在等待的时长。关闭再开启 Auto、手动推进、新交互或绑定版本变化会建立新周期。
- 当前 Dialogue 快照保存冻结间隔，恢复不会因为全局偏好改变而重算。旧快照缺失间隔时使用作者值；非法范围拒绝恢复。Auto 的计时继续是 Player 瞬态，不承诺跨读档保存进度。

设置页提供两种倍率控制，正文区域滚动，标题与关闭按钮固定；绘制与命中使用同一裁切范围。设置滚动不关闭 Auto。

## 时钟与保存

活动音频即使是唯一剩余效果，也保持 Story Tick，使已揭示对白停留期间的音频 offset 持续累积。菜单暂停冻结 Story 逻辑及 Voice/Sfx 设备声音，BGM 默认继续；作者菜单音乐替换时另行暂停旧 BGM。Foreground UI 使用独立设备时钟。此修正会使纯音频停留场景继续调度 Tick；尚未引入低频音频时钟调度优化。

读取快照保留绑定及具体实例，并让任务回收保留被引用的声音元数据。恢复校验绑定版本、非循环 Voice 类型、引用存在性及能力；尚未提交的 Dialogue 不允许携带已绑定状态。声音资源仍按活动播放需要准备，不因已结束的绑定永久保留媒体。

本轮未发行的 snapshot v2 增加缺省为空的 reading 字段；没有绑定时与旧行为一致。Source/runtime/content 版本不变，新能力由 requires 声明。跨发行存档仍不迁移。

## 历史语音重播

执行显式 `DialogueVoice` 绑定时，历史记录保存该对白 interaction、音频素材、原始 gain 和实例去重键。同一句在 Gate 后绑定的多段语音按绑定顺序保存；重复绑定同一实例不重复播放，解除当前绑定不删除此前的记录。不根据活动 Voice 总线猜测历史语音。旧快照缺少这些可选字段时仍可查看文本，不提供语音按钮。

内置历史页提供重播、停止和失败重试，正文工具栏提供入口。重播是一个独立的 ForegroundUi/Voice 播放器，使用玩家 Voice 音量；不运行 VM、不推进正文时钟、不修改变量、检查点或已读记录。同一时间只重播一行，行内多段依次播放，每次只准备当前一段。更换记录、翻历史页、关闭历史、读档、换会话或设备丢失都会停止或取消它；过期资源和音频回调不能启动下一段。

历史元数据不保留旧任务或解码声音。分模块版本通过根索引验证音频身份，重播时只按需获取当前素材 catalog，不重新获取旧章节的 Code、Static 或 Text；加载存档也不下载所有历史语音。取消准备后的预算保留到宿主确认物理取消。失败仅在对应行显示重试，不使正文进入故障状态。

冷启动恢复 sampled_remaining 绑定时，需要先按需准备被绑定声音的 catalog，才能验证时长；该元数据在绑定仍存在时保留目录租约。已结束的绑定只需要目录元数据，不重新准备或播放媒体。这项恢复依赖与历史重播分开，不能据此加载整份历史的音频目录。

单条历史最多保存 64 个语音实例，整体仍受 1000 条和 4 MiB 文本/说话人/语音及选择元数据预算限制。超出单条预算时舍弃整条记录，避免发布不完整的语音序列；派生历史的预算不使有效作者指令报错。恢复校验实例去重、身份范围、音频类型、有限 gain 和能力声明；历史实例键不是对当前活动任务的引用。读档刷新活动对白交互 ID 时，同步更新对应历史关联，后续 Gate 绑定仍加入同一记录。

作者的 history_window/history_flow 可显式设置 `voice_controls: true`，需要 `ui.menu-history-voice.v1`；缺省关闭，旧菜单布局保持原行为。生成控件使用同一个独立重播路径，只有当前菜单中可见、启用且完整落在裁剪区内的控件能启动重播；滚动、翻历史页、隐藏、禁用、关闭或布局裁剪都会取消当前重播。窄屏固定窗口按实际可见容量翻页，最新及最早记录均可到达。具体布局、预算和输入授权见 [连续历史语义](MENU-HISTORY-FLOW-SEMANTICS.md)。

## 历史选择记录

只在 `Choose` 实际提交、到期提交默认项或声明的 `CancelChoice` 生效时追加历史；待选择状态、光标移动、禁用项、隐藏项、过期输入和无可选项的 `on_empty` 路径不产生选择记录。记录保存原始 interaction、选择 ID、当时实际展示的选项标签和 enabled 状态、每个标签的文本契约身份、原正文语言和字体计划，以及 selected / timed_out / cancelled 结果；不保存或再次提交选项值、分支目标或条件表达式。

内置历史、作者 `history_window` 和连续 `history_flow` 显示“选择”“自动选择”或“取消选择”。选中和超时记录显示实际选中标签；取消记录显示当时展示的标签，不推测选中项。完整展示项列表保留在快照元数据中，当前界面不会重新开放这些选项。状态标题使用当前界面语言和界面字体，选项正文保留当时的正文语言与字体。连续历史把标题纳入真实测量、裁剪、可见文本预算和滚动锚点；重排、界面语言变化和跟随最新记录仍保留相应定位。查看、关闭或尝试对选择记录重播语音不修改剧情、变量或已读状态。历史保存状态在标题下单独显示，不覆盖标题或记录。

选择记录与对白共同受 1000 条及 4 MiB 内容元数据预算限制；超过单条预算时整条舍弃，保留已有历史，剧情提交照常完成。旧快照缺 `choice` 时仍按普通文字历史恢复。恢复验证选择的根索引身份、展示项唯一性、文本契约、原字体计划、结果必须指向一个原展示的 enabled 项，以及显示字段和元数据一致性；拒绝混入语音元数据的选择记录。完成的历史是被动数据，不是剧情执行授权；旧模块已回收时不加载旧 Code、Static 或 Text，也不重新评估标签和条件。根索引不包含旧选项到文本的完整映射，因此这些结构及文本身份检查不证明已卸载模块内的选项关联；保存摘要用于检验存储数据完整性。

## 验证范围

Core 测试覆盖 Gate 后绑定、阻止 Advance 穿越 Gate、同名新实例不篡改旧绑定、坏快照和缺失能力。Player 测试区分并行/语音后等待、显式无语音与旧总线策略，并检查纯音频位置推进和菜单冻结。浏览器 fixture 使用正常编译的绑定指令，并在无视觉动画/淡出的已揭示页面上保存/恢复实际设备音频位置。

硬件输出延迟与人工听感不由这些测试证明；Windows 真机和硬件 WebGPU 尚待认证。具体测试结果见 NIR-NEXT-PROGRESS.md。

## 按住快进

`HoldSkip { pressed }` 是宿主发给 Player 的瞬时输入，不是剧情指令，不写入存档。它与 ToggleSkip 的锁定状态分开；释放 Ctrl 不取消显式开启的锁定快进。有效快进仍只作用于已读 Dialogue，不能越过硬 Gate 或选择。遇到未读时解除按住状态，须重新按键才能再次请求。

按下只在未暂停、无选择的 Story 接受；菜单、后台、会话切换和恢复解除按住状态。Web 在 keyup/blur/后台释放，编辑控件与 IME 优先；左右 Ctrl 分别跟踪，最后一键松开才释放。Windows 使用同一语义输入，分别跟踪左右键；失焦与遮挡按或关系暂停，恢复其中一个条件不解除另一个。原生 Windows 路径尚待实机验收。

这不代表 P2.2 已完成：来源隐藏政策的实证映射与原生完整焦点导航仍是后续工作。

## 共享背景与主键路由

指针与无焦点 Enter/Space 的动作判定在 nir-presentation 中共享，两端宿主只映射物理事件。左键先检查最上层语义区域；禁用区域消费命中，不能穿透到下层或回退为背景推进。空白背景仅在未暂停、未加载、无选择且有对白的 Story 产生 Advance。仍由 Engine 先处理阅读视口翻页，再交给唯一 Core，因此不会将视口页混为源页或穿越 Gate。

右键在 Story 打开菜单，在系统子页关闭；标题右键不启动入口。无焦点主键只使用实际可用的新游戏/继续入口，不能在子菜单自行猜测动作；脚本隐藏对白保留既有继续路径。Web 编辑控件、IME 和已聚焦按钮先处理按键。原生完整 Tab/方向键焦点导航仍待交付。

点击要求按下/抬起目标和交互仍一致且移动小于 20 逻辑像素；拖动、取消、离开画布或会话切换不能激活旧目标。Windows 同步接入，尚未完成原生设备验收。

## 玩家临时隐藏

工具栏“隐藏”或无编辑焦点的 H 使用独立的 Player 呈现遮罩，隐藏对白与剧情工具栏，保留场景。它不写入 Core 快照，也不改写脚本 DialogueVisibility 或消息根外观。第一次左键/右键、Enter/Space、H 或菜单操作只恢复呈现，不揭示文字、不翻视口、不推进源页。脚本原本隐藏的对白仍保持隐藏。

新项目默认 `continue_story`：关闭 Auto/锁定快进/按住快进，继续 Story、文字揭示、作者动画和声音。恢复不自动重新开启阅读模式。默认行为不是对所有来源引擎的兼容声明。

有证据需要冻结 Story 的工程可在 player.toml 显式配置：

```toml
[defaults]
hide_policy = "pause_story"
```

此非默认配置使用 `player.hide-policy.v1`；编译器按实际配置推导声明，源验证和惰性 runtime root 都拒绝缺声明。PauseStory 使用独立暂停 owner，暂停 Story 及其音频，Foreground UI 不随之暂停；恢复只释放自己的 owner，不解除后台、设备或其他暂停。当前仅支持 continue_story / pause_story 两种政策，不隐含“暂停剧情但继续某条音乐”等尚未定义的组合。

只在 Story 有活动对白、无选择且不处于加载/暂停时接受隐藏。新会话、恢复、结束、选择或故障解除遮罩，避免进入不可操作的隐藏交互。导入器暂不据引擎名称猜测来源隐藏/音乐政策；来源证据映射仍属于后续认证。

默认顶部/底部对白与自定义 rect 都显示静态阅读提示。自定义框优先在框下或框上放置提示；没有外部空间时使用底角覆盖提示，不压缩或改动源文字边界；溢出阅读时移除提示及其底板，由现有翻页控件提供导航。提示不引入循环动画或新的时钟请求。

## 键盘控件焦点

播放器共享 KeyboardFocus 选择规则：Tab/反向 Tab 按语义声明顺序，方向键从当前控件中心选择目标方向内距离最近的可用控件，垂直于行进方向的距离权重为 4；没有候选时保留焦点。禁用、零面积和完全在屏幕外的控件不参与。无焦点时选第一个（反向 Tab 选最后一个）。

焦点绑定会话、交互、页面、控件 ID 和动作；页面重投影后身份不匹配即清除，不能因数字 ID 复用而激活新动作。确认键优先激活有效焦点，未聚焦时沿用既有主键规则。焦点只在呈现层，既不写剧情快照，也不增加 NIR 作者能力声明。

Web 的语义按钮获得 DOM 焦点，编辑/IME/宿主页面优先；播放器列表边界保留浏览器默认 Tab，从而能访问列表外的宿主控件。Windows 控件内循环，鼠标点击或窗口失焦清除键盘焦点，并使用共享绘制路径的焦点边框。在滚动区域的可见控件边界，Tab/反向 Tab 或上下方向键先滚动一个有界步长，再重新投影并选择新露出的可用控件；没有新控件时尽可能保持原动作。Web 等新语义按钮创建后再设置 DOM 焦点，并复查会话/交互/页面；Windows 同步使用焦点中心请求原图菜单 hover 反馈。设置页窄屏往返已在浏览器验收；长选项、多行超高控件与后续自定义集合仍需专项验收，Windows 实机尚未验收。


## LiveNovel 配置映射

转换器读取 LPB116 的作者系统默认值（不读取玩家存档或个人偏好）：音量 0–1000 转为 0–1，StatusAutoTextWait 的毫秒值转为固定等待微秒。StatusTextSpeed 的单位为每字符毫秒（0 瞬时），由固定滑条回调 `StatusTextSpeed = @ParamStr[0] × 64` 与官方文档的每字符毫秒语义双重认证；导入时换算为每字素簇微秒的揭示间隔（玩家字速偏好在 Core 侧作为除数生效）。字体面（系统字体，工程之外）不迁移，见导入账本 `livenovel.text.font` 近似。

读取原页结束/事件脚本的 Auto Timer，要求其 delay 是 StatusAutoTextWait + tm；同时核对设置回调将输入乘 1000 写入该变量、显示时除以 1000。临时变量链通过有界纯表达式归一化识别，未知控制流、额外副作用或不同单位均报错。导入绑定使用 sampled_remaining，对已支持的单一非循环 Voice 保留采样计时，不能将其替换为“语音结束后另起完整等待”或“与语音并行等待”。多个来源语音通道仍不在当前导入支持范围，硬件播放位置/原版实际调度精度尚待实机认证。

新语义仅扩展配置和现有绑定的枚举，未增加任意回调、表达式执行或第二条剧情流。Source/runtime 仍使用能力声明；快照保存绑定策略，Auto 周期进度仍是 Player 瞬态，读档后重新建立周期。

## 角色语音偏好

角色键使用作者在 Dialogue.speaker 中声明的原始文本引用（如 speaker.aki），不使用翻译后的显示名或音频文件名。DialogueVoice 的显式绑定为对应的非循环 Voice 实例保留该键；绑定在声音开始后到达时，更新原实例的增益，不重新起播。未绑定声音、循环 Voice、BGM/Sfx 和无名对白继续使用总线音量。

内置设置列出当前对白和仍保留的阅读历史中已知的有语音角色，不获取旧章节正文或提前暴露未读角色。显示名保持该记录的冻结语言和字体，切换语言不改变角色键。每行提供 44px 的减小、静音/取消静音和增大控件；静音保留先前音量。角色名单与覆盖值各有 128 项预算，角色引用最多 256 UTF-8 字节；只投影可见行，满预算时新覆盖控件禁用，恢复默认值会释放覆盖条目。

Preferences.character_voices 保存各键的 volume（0–1）和 muted（布尔值）；缺字段的旧偏好使用总音量。同步启动和原生异步加载均移除未知引用及非有限音量，夹紧有效音量并执行条目预算。有效语音增益为作者 gain × 总 Voice 音量 × 角色倍率，作者包络独立计算。Web 与原生即时更新正文及前台历史重播的原实例，不改变任务终态、演出或剧情进度；静音的实例不要求 Web 输出恢复。sampled_remaining 开始周期时，角色有效倍率为零不增加采样余量；parallel/after_voice 继续保留原绑定任务等待政策，可用 auto_wait_voice 关闭额外等待。作者 Await/Gate 始终保留。

角色覆盖与其他全局偏好按作品/存储 profile 保存，读档不回滚它们。任务、对白和历史保存身份，历史重播使用当前覆盖。旧存档只从已验证的作者说话人引用和无歧义的任务绑定恢复身份；已无该关联的旧历史保持总音量，不按译名猜测角色。作者应保持说话人引用稳定；不同角色引用可以拥有相同显示名。
