## 新增验证

独立 `novelc init` 工程将双语 intro 扩展成 24 段带编号的文字，将 Gate 前文字扩展为 16 行，并设置 24 个稳定 ID 选项（包含超长标签、一个禁用项），使用 1.5 倍字号。

浏览器验证手动揭示后保留顶部、连续 Advance 翻阅而不离开对白、旧交互实例不能滚动、PageUp/PageDown、滚轮和模拟触摸指针滑动、390×600 与 844×390 重排、保存后刷新读档、回看长记录、Gate 等待时不越过正文，以及能通过键盘到达第 24 个选项并走到预期结局。最后切换英文并重新开启长对白，检查实际画布和英文翻页按钮。既有回归继续覆盖两条剧情路线、设置、恢复、错误重试、设备损失、生命周期与诊断。

开发预览用例启动真实 `novelc dev`：写入损坏 JSON 后，状态接口和错误条报告失败，发行及原对白/交互保持；修复正文后自动完整重载并显示新内容。作品锁不变，生成报告不触发重载；普通静态服务器没有开发状态路由，磁盘发行 HTML 不含开发助手。

原生新增用例覆盖实际字体测量、仅已揭示区域可滚动、重排锚点、自动/手动阅读切换、长记录内部阅读、全部 24 个 OptionId 可达、禁用状态和有界点击区域、混合 LF/CRLF/CR/LFCR 与强调段落的原 UTF-8 偏移、英文翻页标签不被裁切，以及监听忽略输出、编辑/删除检测、损坏候选不能替换发行通道。
