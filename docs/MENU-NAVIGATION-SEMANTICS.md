# 有界菜单子页导航

`ui.menu-navigation.v1` 在已有菜单服务上增加两项作者动作：`push_menu {menu}` 进入子页并保存父页的局部值；`back` 返回一层。它们只能由当前菜单的 instance／revision／control 请求触发，没有不受控的宿主 push/back 请求，不增加剧情控制流。

```toml
[[image_menus.system.elements]]
id = "history"
rect = [80, 300, 500, 60]
content = { type = "hit_region", label = "History", action = { type = "push_menu", menu = "history" } }

[[image_menus.history.elements]]
id = "parent"
rect = [80, 560, 500, 60]
content = { type = "hit_region", label = "Back", action = { type = "back" } }
```

## 状态和输入

一个导航上下文最多保存八个父页。父页记录仅有静态菜单 ID 和现有最多 32 项有界 Bool／I32／枚举局部值；没有媒体租约、历史全文、服务请求、保存确认、hover、焦点或任意脚本。导航页 ID 和 push 目标最多 128 字节；旧的、未使用导航动作的菜单不新增此 ID 限制。到达上限时 push 控件禁用，提交端也拒绝；静态递归声明仍由运行时深度限制约束，不自动执行递归动作。

子页以初始局部值创建。返回恢复父页的局部值，但分配新的菜单实例并重新求值 Profile、偏好、槽位、阅读权限和故事只读条件；旧父页、旧子页输入不能使用新实例。重新打开已经退出的根菜单仍从初始值开始。页面关闭、恢复／新游戏等会话切换清除相应导航链。

`back` 在根页禁用且提交无效。共享 Close（Escape、右键和内置返回按钮）在有父页时返回一层；没有父页时保留原来的返回上下文。保存确认优先消费 Close 以取消确认，第二次 Close 才返回父页。标题子页也支持 Escape／右键返回；标题导航链在临时系统覆盖期间与覆盖页导航链分别保存，各自最多八层，关闭覆盖后恢复原标题局部值和链。

原 `menu {menu}` 仍替换当前页，不保存当前页，也不凭空创建父页；在已有导航链中只替换当前顶页。原 Settings／Saves／History 动作仍进入内置服务页并采用原返回政策，不自动变成新的作者子页。Auto／SkipRead 关闭整个系统菜单后进入 Story；PeekStory 保留当前菜单和导航链。系统菜单的逐层返回始终保持 Story 暂停，不注入推进输入。

## 资源与边界

系统覆盖只为当前页准备和留存图片。push 或 back 取消离开页自己的准备、释放其图片，目标页按原准入规则重新准备；返回可在子页加载或准备失败时通过共享 Close 执行，迟到回执不能切回旧子页。框架不保存父页媒体或扩大原媒体预算。标题页沿用已有标题导航闭包准备政策，不能以此宣称已完成 P4 的页面效果／媒体 owner。

连续历史等布局状态仍属于当前呈现实例，重新进入会重新准备并采用该控件已有定位政策；本能力保存的是菜单局部值。需要返回时保留历史滚动锚点、演出进度或组件内部状态的来源仍须独立映射，不能把上述局部值保存扩称为任意页面快照。

源 Program 与 Runtime 根均验证能力、静态目标和菜单服务闭包；overlay 的 push／replace 可达页都禁止未隔离 Entry。编译器仅在实际使用动作时保留声明。源／Runtime／Snapshot 版本不因这项瞬态菜单状态变化升级；页面链不写故事存档。

Web 和原生宿主调用同一 Close 与控件服务。软件 WebGL2 的实际输入／像素和 Windows 目标类型检查分别记录，Windows 设备仍需独立验收。来源历史页 Escape 删除历史容器并恢复父菜单，可由该导航能力表达；图片、布局、历史范围和其余回调仍需转换器规则和实际播放对照，不能仅生成 push 链接便宣布迁移完成。
