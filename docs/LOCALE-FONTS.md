# 独立语言上下文与字体计划

当前 v1 开发格式将界面语言和正文语言分开管理。作者可组合中文界面与英文正文，并为每种语言指定有序字体计划。首版支持 `zh-Hans` 和 `en`，同一发行内的两种正文均须完整，不支持运行时下载正文包。

## 配置

在 `game.toml` 的输入中登记 `config/locales.toml`：

```toml
[inputs]
locales = "config/locales.toml"
```

配置文件示例：

```toml
format = 1
default_ui = "zh-Hans"
default_text = "zh-Hans"

[ui]
zh-Hans = ["font.cjk"]
en = ["font.latin", "font.cjk"]

[text]
zh-Hans = ["font.cjk"]
en = ["font.latin"]
```

`ui` 和 `text` 分别列出作品支持的语言及有序 Font AssetId。首个覆盖字形的字体作为主字体，后续字体是作者明确选择的 fallback；播放器不会偷偷使用系统字体补缺。每个计划不能为空、不能重复引用同一 AssetId，所有引用都必须是已登记的字体资源。默认语言必须存在于对应表中。缺少配置、正文包或字形覆盖会在 `novelc check` 阶段给出错误，不能发布不完整的语言版本。

编译器为界面和每种正文分别收集所需字符。共享字体先合并所有引用计划的字符集，再只生成一个字体对象。可枚举插值、角色名、选项、标题和控件也会加入覆盖检查。字体来源、许可及 subset/full 配置参见[字体说明](AUTHOR-FONTS.md)。

## 运行时选择和切换

浏览器按 `navigator.languages` 的顺序，分别在 UI 与正文支持集合中寻找精确语言匹配；英语区域标签映射到 `en`，简体中文仅匹配简体中文。不会把繁体中文自动降级为简体。首次使用时未匹配的表面回退到作品各自默认值。已保存的玩家偏好优先于浏览器语言；旧版只有 `locale` 字段的偏好会迁移为相同的 UI 与正文语言，并保留音量等其他设置。

设置页分别修改 UI 与正文语言。播放器先准备候选字体、文本布局和辅助语义，再一次性提交；准备时剧情暂停。连续切换会使旧候选失效。失败时保留之前生效的两个语言，可重试或取消；语言准备失败不会变成剧情任务失败。玩家 UI 偏好单独保存在浏览器，不会随读档或回退恢复。

UI 切换只影响新绘制的界面。正文切换在新对白或新选项实例化时生效；已打开的对白、选项及历史都冻结实际语言、正文内容和字体计划身份。设置、读档、回退或设备恢复不会改写这些实例，后续新实例再使用当前偏好。不同语言的历史条目可在同一页面使用各自字体计划。

## 严格兼容与排错

新增语言配置和冻结字体身份属于 v1 研发格式的破坏性迭代：旧 `Program`、运行数据及不兼容快照会严格拒绝，不会把旧存档自动转换成新发行。请使用配套 SDK/CLI，并重新构建发行。`E_LOCALE_CONFIG` 指向缺失或错误的语言配置；`E_FONT_PLAN` 指向空计划、错误资源类型或未准备字体；`E_FONT_COVERAGE` 会列出缺失字符及码位。

可运行 `novelc check --locked` 验证配置与覆盖，运行 `novelc build --locked` 生成发布目录。本阶段浏览器验证记录位于源码仓库 `docs/validation/locale-fonts/`，并明确区分软件适配器和物理 GPU 结果。
