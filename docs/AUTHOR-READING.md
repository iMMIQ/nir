# 作者长内容与开发预览

此阶段让作者能在独立作品中编写较长对白、较多选项，并在保存文件后直接查看结果。作品格式仍为一个模块的 NIR JSON 与双语 TextDoc；没有新增脚本语言、NVL 或编辑器。

## 阅读行为

对白与回看按实际字体塑形结果确定可滚动高度。整段排版与逐字揭示分离；浏览范围只包含已经揭示的行，不能借翻页跳过 Gate。自动揭示时跟随最新文字；普通手动模式下，揭示至 Gate 或段尾时保留当前视口，然后可逐页阅读。

- 点击对白或按空格 / Enter：先揭示，随后向下翻页；到达已揭示文字底部后，才执行正常的剧情推进。
- PageUp / PageDown、鼠标滚轮、上下滑动或画布上的「上一页 / 下一页」：只移动阅读位置，不发送 VM 的 Advance。手动翻页会关闭自动阅读和快进。
- Gate 等待期间仍可翻阅此前文字。只有剧情的 DialogueContinue 能释放 Gate。
- 窗口或字号变化时，手动阅读尽量保留顶部逻辑字符；自动跟随状态继续跟随已揭示末尾。
- 回看原有的前后记录分页保留；每一页内部的长记录另有滚动区域。

选项使用与 GPU 文本渲染相同的字体和宽度测量。主题 `item_height` 是最小高度，长标签自动增高；选项列表拥有固定视口，仅投影与视口相交的按钮，文字、背景和点击区域都裁切到视口内。OptionId、启用条件和交互实例校验保持不变；PageDown 可以到达末尾选项，再以 Tab / Enter 选择。辅助 DOM 只映射当前可见按钮，普通视觉按钮仍由 Rust / wgpu 绘制。

阅读位置是呈现状态，不写入逻辑快照。读档、回退或新会话会重新定位到该对白当前已揭示末尾；存档中的全文实例、揭示进度、Gate、变量及任务不受影响。设备重建保留当前阅读状态。选项重排后只钳制滚动偏移，尚无按 OptionId 保持滚动锚点。

## 开发循环

使用本分支源码构建的配套 CLI / SDK：

```sh
novelc init my-story
novelc -p my-story resolve
novelc -p my-story dev
```

默认地址为 `http://127.0.0.1:4173/`，可以用 `--port` 修改。首次构建必须成功才能开启服务器；初始错误会输出诊断并退出，修复后重启命令。

开发服务器每 250 毫秒检查工程内文件的路径、大小和修改时间，等待约 500 毫秒稳定后，在 `.nir/preview-candidate/` 执行锁定构建。构建期间文件再次变化时，候选不会发布，而是等待新的稳定版本。成功后校验并复制完整内容对象，最后原子替换发行通道；浏览器检测到新的发行身份后自动完整重载。

编译失败时，之前的发行和正在播放的会话保留。开发错误条显示错误码和作者位置；保存修复后的文件会自动重试。开发助手仅由 `dev` 的 HTTP 响应注入，`build` 的产物与 `serve` 不携带该助手或状态路由。

**成功重载从标题入口重新开始，未保存进度会丢失。** 当前只接受精确发行匹配的存档，因此不要依赖旧发行存档继续新内容。自动重载没有更换运行中的 VM、迁移快照或重复执行部分 Cue；安全热更新仍未实现。

监听忽略 `.git/`、`.nir/`、`dist/`、`reports/`、`target/`、`node_modules/` 和 `game.local.toml`，不跟随目录符号链接。保留大小及修改时间的外部同步可能不触发检测，需要重新启动 `dev`。SDK 在工程外时不被监听；升级 SDK 后显式 `resolve` 并重启。开发服务器只绑定本机，旧的哈希对象保留到清理开发输出为止。

## 验证和限制

浏览器回归使用独立 `novelc init` 工程，扩展至 24 段带编号的正文、长 Gate 前文本、24 个稳定 ID 选项（含禁用项），在大字号、窄屏与横屏下操作。具体运行证据见 [本阶段报告](validation/author-reading/README.md)。

这次没有引入按预算分片的字体塑形或无限长度保证。超长单段、数千选项、完整长篇、多模块、真实移动设备和硬件 GPU 性能仍需单独验证。后续已加入 [字体编译和独立模板](AUTHOR-FONTS.md)；《雨后书简》的旧子集字体仍不能直接覆盖任意新中文。已发布的旧 SDK 不会因源码合并而自动升级。
