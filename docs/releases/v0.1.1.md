# NIR v0.1.1

本版本完善首版发行流程与桌面浏览器支持。

## 主要更新

- 新增 `novelc release stage/verify/promote/rollback`：本地和 HTTP(S) 发行校验、频道冲突检测、晋级与回滚。
- 固定发行启动入口，存档按游戏、开发/发布环境和发行隔离；支持历史发行续玩及导出。
- 标准 WASM 同时支持 WebGPU/WebGL2，包含启动回退、设备/上下文恢复及实际后端诊断。
- 完善多模块按需加载、驻留驱逐、准备调度、媒体预取、独立语言与字体处理、作者预览和 Bun 测试流程。

- 修复预览服务器在并发长连接下偶发停留于加载界面的问题。

## 下载与使用

- `nir-0.1.1-linux-x86_64.tar.gz`：CLI、SDK、文档及《雨后书简》静态示例。
- `nir-0.1.1-source.tar.gz`：对应标签的完整源码。
- `SHA256SUMS`：文件校验值。

CLI 在 Ubuntu 24.04 构建，需要 x86_64 Linux、glibc 2.39 或更新版本及 libstdc++。使用 NixOS 或其他环境可从源码构建。将 `novelc` 与 `sdk/` 保持在同一目录，创建作品无需安装 Rust：

```sh
./novelc init my-story
./novelc -p my-story resolve
./novelc -p my-story check --locked
./novelc -p my-story build
./novelc serve my-story/dist/full/web
```

桌面验收覆盖 Chromium WebGPU/WebGL2 和 Firefox WebGL2；Safari、移动端及实体 GPU 验收后续安排。发行操作详见包内 `docs/M4-RELEASE.md`。
